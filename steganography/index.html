How it works: the least significant bit (LSB) of every pixel / audio sample / video frame byte is overwritten with your message bits — the change is invisible and inaudible. Output formats are always lossless (PNG, WAV, uncompressed AVI) so no hidden bit is destroyed by compression.

Tip: to store a video, image or audio inside a video carrier, choose “File” as the payload and pick it — extraction returns the original file byte-for-byte.
