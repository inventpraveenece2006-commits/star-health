About

StegoVault

A modern hands-on guide to steganography.

What is steganography?

Steganography hides data inside other, innocent-looking data. Unlike encryption — which makes a message unreadable but visibly scrambled — steganography makes the very presence of the message unnoticed. Here the carrier files look like ordinary photos, songs and clips.

How the hiding works

Digital media is made of bytes: pixel values in images, audio samples, and video frame bytes. Each byte's least significant bit is only 1 / 256 of its value — invisible to the human eye or ear. StegoVault swaps the carrier's least significant bits for the bits of your secret.

  1. Pack — your text or file is wrapped in a length-tagged container (magic header STE1 + size), so extraction always knows exactly where the payload starts and ends.
  2. Encrypt — if a password is given, the payload is sealed with AES-256-GCM before embedding.
  3. Substitute — the encrypted bits overwrite the carrier's least significant bits, one bit per sample/pixel byte.
Supported combinations
  • Text → Image (PNG / BMP / JPG / GIF / WebP / TIFF)
  • Image → Image
  • Text → Audio (WAV / MP3 / FLAC / OGG / M4A)
  • Image / Audio / Video → Audio
  • Text → Video (any cover, output uncompressed AVI)
  • Image / Audio / Video → Video
  • Text or any file → Any file (documents, archives, music, …)
Important limitations
  • The extracted carrier is always re-encoded as a lossless file (PNG/BMP, WAV or AVI). After saving it, do not re-encode, compress or convert it again, or the hidden bits are destroyed.
  • Compressed covers (JPG, GIF, WebP, MP3, FLAC, MP4, MKV…) are decoded first — you get a lossless PNG/BMP/WAV/AVI with slightly different appearance/size than the original.
  • For the any-file carrier, files with their own integrity checks (ZIP, DOCX, MP3, MP4…) may refuse to open after editing, so prefer PNG, BMP, WAV or plain documents for guaranteed results.
  • A carrier can only hold so much: roughly one bit per pixel byte (image), per sample (audio), per frame byte (video), and per file byte.
  • Video output is raw uncompressed AVI — play it with VLC / mpv; Windows Media Player does not support this container.
  • Passwords are not stored anywhere — if you lose the password, the payload cannot be recovered at all.
